# План замеров

Веб-приложение для телефона: обмер помещений лазерным дальномером (по Bluetooth как клавиатура), поэтажные планы, PDF и DXF для AutoCAD.

**Открыть:** https://nurislamturgunbaev-lab.github.io/disto-plan/

## Начало работы
- Приложение открывается пустым. **«+»** вверху — новый лист: **наименование, блок, этаж**.
- Чертёж DWG/DXF можно загрузить (Меню → «Загрузить план») — он ляжет **подложкой красным**, свои замеры — **зелёным**. Только тогда есть режим «Стены» и сравнение с чертежом.

## Замер
- **Слева**: «спереди / сзади» (спереди вычитается 0,13 м, число меняется только в меню), **налево / направо**, под ними **прямо** и **вернуть**.
- **Направление + метр**: выбрали направление — лазер записал длину. Комната замыкается сама, если углы сошлись точно; иначе — кнопка «Замкнуть» внизу (невязка сохраняется и показывается).
- **Нарисовать пальцем**: точки на плане, нажатие на первую точку замыкает комнату — и сразу начинается замер стен по очереди (против часовой), форма подстраивается под размеры. Нажатие на стену готовой комнаты — перемерить её.
- **Ручной ввод** — своя цифровая клавиатура (⌫ — стереть цифру, ✕ — выйти без изменений). Русская раскладка лазера («ю») понимается.
- **Полный экран** — только план и пульт; справа — дверь и окно.

## Двери и окна
Ставятся по стандарту (дверь 0,90 м, окно 1,50 м): одна — по центру стены, несколько — с равными промежутками. Передвинутая вручную остаётся на месте. Два нажатия — изменить.

## Этажи
«−» / «+» — другой этаж; соседний обмеренный этаж показывается бледной тенью. Каждый этаж — отдельный чертёж. Нажатие на номер — ввести этаж. «Очистить этаж» — в инструментах.

## Как в AutoCAD
Привязки (конточка, середина, нормаль, ближайшая), орто, **полярные углы 5°**, **поворот плана по текущей линии** с компасом, **рулетка** (расстояние и площадь), толщина стен (Меню, см), **слои** (чертёж, тень, размеры, площади, проёмы, толщина, штриховка, текст, «Повторить», копировать/повернуть/зеркало), перестановка кнопок.

## Отчёты
- **Telegram** — собирает PDF поэтажный план + DXF этажа + DXF всех этажей (только этажи с замерами) и открывает «Поделиться».
- PDF — только поэтажный план, рамка **A4 или A3 и масштаб подбираются автоматически**, штамп с датой и строкой «План составил».
- DXF в миллиметрах: чертёж — красным (цвет 1), замеры — зелёным (цвет 3). В AutoCAD «Сохранить как» → DWG.
- Все файлы хранятся в «Документах».
