# DISTO · План замеров

Веб-приложение для телефона: план этажа по блокам, замеры лазерным дальномером **Leica DISTO X3** (и другими DISTO с Bluetooth) с любого этажа вверх или вниз, автоматическая запись, правка, выгрузка в AutoCAD.

**Открыть:** https://nurislamturgunbaev-lab.github.io/disto-plan/

## Возможности

- **План по блокам.** Встроен план секций А, Б, В, Г. Можно загрузить свой **DWG или DXF** (Меню → «Загрузить план»): приложение само делит чертёж на блоки и подписывает их по буквам на чертеже. Блоки можно переименовать.
- **Этаж и направление.** Вверху: этаж (− 16 +), «↓ Вниз / ↑ Вверх», «до этажа». Проектное значение = разница этажей × высота этажа (задаётся в меню), его можно изменить у каждой точки.
- **Автозапись с DISTO.** Подключите прибор кнопкой «DISTO». Каждое нажатие кнопки измерения на приборе записывается:
  1. в выбранную точку, если она ждёт значение (или нажато «Перемерить»);
  2. иначе в самую раннюю ожидающую точку этого этажа;
  3. иначе создаётся новая точка в центре экрана — её можно перетащить на место.
- **Инструменты:** «Точка» (вертикальный замер), «Размер» (линия между двумя точками с привязкой к углам, сравнение с чертежом), «Чертить» (линии эскиза), «Выбор» (перемещение), «Отменить».
- **Правка:** нажмите на точку — откроется карточка: значение, проект, этаж, направление, примечание, «Перемерить», «Удалить». Точки и концы размеров перетаскиваются пальцем.
- **Ввод с клавиатуры:** поле внизу экрана (например, `2,85` и ✓). Режим клавиатуры DISTO (Bluetooth HID) тоже работает: цифры попадают в это поле.
- **Единицы:** все значения в метрах, два знака после запятой (`1,00`).
- **Выгрузка (Журнал):**
  - **DXF для AutoCAD в миллиметрах**: план блока, слои `ЗАМЕРЫ`, `РАЗМЕРЫ`, `ЭСКИЗ`, `ПЛАН_КОЛОННЫ`; вариант «все этажи» раскладывает замеры по слоям `ЗАМЕРЫ_ЭТ16` и т. д.;
  - Excel (CSV), картинка PNG;
  - резервная копия JSON (Меню → Данные).
- Работает **без интернета** после первого открытия; данные хранятся в телефоне.

## Телефон и Bluetooth

| Телефон | Как подключить DISTO |
|---|---|
| Android | Откройте ссылку в **Chrome**, нажмите «DISTO», выберите прибор. Можно «Добавить на главный экран». |
| iPhone | Safari не даёт сайтам доступ к Bluetooth. Откройте ссылку в бесплатном браузере **Bluefy** (App Store) или включите на DISTO режим клавиатуры. |

На DISTO X3 включите Bluetooth (значок BT). Если значения не приходят, откройте Меню → «Журнал Bluetooth» и пришлите его содержимое: там видны все данные от прибора.

## Файлы

- `index.html`, `css/`, `js/app.js` — интерфейс
- `js/disto.js` — Bluetooth DISTO
- `js/cad.js` — чтение DWG/DXF и разбивка на блоки (библиотека [libredwg-web](https://github.com/mlightcad/libredwg-web), GPL-3.0, в `lib/`)
- `js/dxf.js` — выгрузка DXF (мм)
- `js/default-plan.js` — встроенный план (из присланного DWG)
